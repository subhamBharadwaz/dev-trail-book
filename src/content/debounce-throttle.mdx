## The idea

Debouncing delays work until calls have stopped for an interval. Throttling limits how often work runs during a continuous stream. A search request often benefits from trailing debounce; a scroll-driven update may need throttling or requestAnimationFrame depending on its purpose.

## Why it matters

A 300 ms debounce reduces request frequency, but it does not resolve out-of-order responses. Request cancellation and stale-result protection solve that separate problem. Clear pending timers when the owning component or subscription is disposed.

## A practical example

```js
function debounce(fn, delay = 300) {
  let timer;
  const wrapped = (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
  wrapped.cancel = () => clearTimeout(timer);
  return wrapped;
}
const search = debounce((query) => console.log(query));
search("r");
search("react"); // only react after quiet
```

## Common mistakes

Recreating the debounced function on every render gives each instance its own timer. Keep ownership stable or implement the timer within an Effect.

## Try it yourself

Type a query rapidly, then pause. Verify one request starts after 300 ms. Next introduce a slow old request to show why debounce alone is insufficient.

## Implement a leading-edge throttle with cancellation

```ts
function throttle<T extends unknown[]>(fn: (...args: T) => void, wait: number) {
  let last = -Infinity;
  const run = (...args: T) => {
    const now = performance.now();
    if (now - last >= wait) {
      last = now;
      fn(...args);
    }
  };
  run.cancel = () => {
    last = -Infinity;
  };
  return run;
}
```

This implementation invokes immediately, drops calls inside the window and has no trailing call. State that contract before using it. Debounce waits for quiet; throttle limits the rate while activity continues. A trailing throttle needs stored arguments and timer cleanup. In React keep the wrapper identity stable where required and cancel timers on cleanup. A UI throttle is not a server rate limiter.
