## The idea

Binary search repeatedly discards a portion of an ordered search space. A lower-bound search finds the first index whose value is at least the target. Using a half-open interval [left, right) makes the empty-range condition left === right straightforward.

## Why it matters

Write the invariant before the loop: values before left are too small, and right is an excluded boundary. Lower bound is not automatically an exact match, so check the returned index and value if the caller asks whether a target exists.

## A practical example

```js
function lowerBound(nums, target) {
  let left = 0,
    right = nums.length;
  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] < target) left = mid + 1;
    else right = mid;
  }
  return left;
}
// O(log n) time, O(1) extra space for sorted random-access input.
```

## Common mistakes

Mixing left &lt;= right with updates written for a half-open interval creates off-by-one errors and nontermination.

## Try it yourself

Test empty input, one element, duplicate targets, and targets below or above the entire array.
