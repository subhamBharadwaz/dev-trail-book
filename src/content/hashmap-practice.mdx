## Why it matters

The underlying question is what information must survive between iterations. Membership needs only seen/not-seen. Frequency needs an integer per key. Explain the invariant and edge cases rather than treating every collection problem as the same template.

## A practical example

```js
function containsDuplicate(nums) {
  const seen = new Set();
  for (const value of nums) {
    if (seen.has(value)) return true;
    seen.add(value);
  }
  return false;
}
function frequencies(text) {
  const counts = new Map();
  for (const char of text) counts.set(char, (counts.get(char) ?? 0) + 1);
  return counts;
}
```

## Complete the second HashMap exercise

```ts
function validAnagram(a: string, b: string): boolean {
  const left = Array.from(a),
    right = Array.from(b);
  if (left.length !== right.length) return false;
  const counts = new Map<string, number>();
  for (const c of left) counts.set(c, (counts.get(c) ?? 0) + 1);
  for (const c of right) {
    const remaining = counts.get(c) ?? 0;
    if (!remaining) return false;
    counts.set(c, remaining - 1);
  }
  return true;
}
```

This compares Unicode code points, not grapheme clusters; normalization and case folding require an explicit product rule. Time O(n + m), auxiliary space O(k).
