## The idea

Build a component around a clear responsibility. Pass information down through props, and move shared state to the closest common parent.

## Why it matters

First build a static version from your data. Then identify what changes through interaction. Values you can calculate from props or state usually do not need their own state.

## A practical example

```tsx
import { useState } from "react";

export function TopicFilter({ topics }) {
  const [query, setQuery] = useState("");
  const visible = topics.filter((topic) =>
    topic.title.toLowerCase().includes(query.toLowerCase()),
  );
  return (
    <>
      <input
        aria-label="Filter topics"
        value={query}
        onChange={(event) => setQuery(event.target.value)}
      />
      <ul>
        {visible.map((topic) => (
          <li key={topic.id}>{topic.title}</li>
        ))}
      </ul>
    </>
  );
}
```
