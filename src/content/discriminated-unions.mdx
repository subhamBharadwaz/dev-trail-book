## The idea

A discriminated union describes a set of alternatives with a shared literal property. Checking that property narrows the value to a particular alternative.

## Why it matters

Instead of unrelated loading, error, and data flags, describe each valid state explicitly. The type checker can then help you handle the possible cases.

## A practical example

```ts
type LoadState<T> =
  | { status: "idle" }
  | { status: "loading" }
  | { status: "success"; data: T }
  | { status: "error"; message: string };

function describe(state: LoadState<string[]>) {
  switch (state.status) {
    case "success":
      return `${state.data.length} topics`;
    case "error":
      return state.message;
    case "loading":
      return "Loading…";
    case "idle":
      return "Ready when you are";
  }
}
```
