## The idea

HTTP is a request-response protocol. A request includes a method, a target, headers, and sometimes a body; a response includes a status, headers, and sometimes a body.

## Why it matters

Treat status codes as part of the API contract. Distinguish transport failures from application errors, and handle empty responses before trying to parse JSON.

## A practical example

```js
async function getTopic(id) {
  const response = await fetch(`/api/topics/${encodeURIComponent(id)}`);
  if (response.status === 404) return null;
  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }
  return response.json();
}
```
