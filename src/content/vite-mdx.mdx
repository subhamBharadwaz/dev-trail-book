## The idea

MDX combines Markdown with JSX. You can write headings, links, lists, and fenced code, then embed React components where an explanation needs interaction.

## Why it matters

Compile trusted content at build time with the official MDX Rollup plugin. Keep each topic in its own file, export metadata, and let Vite discover the collection.

## A practical example

```js
import mdx from "@mdx-js/rollup";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    { enforce: "pre", ...mdx() },
    react({ include: /\.(jsx|js|mdx|md|tsx|ts)$/ }),
  ],
});
```

## Try it yourself

Create a new topic file with metadata, two headings, a code block, and one question. Confirm it appears in the library.
