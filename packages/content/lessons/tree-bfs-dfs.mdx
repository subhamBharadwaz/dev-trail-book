## The idea

Breadth-first traversal explores by distance in edges from the root; depth-first traversal follows one branch before returning to alternatives. A queue expresses BFS. A stack or recursion expresses DFS. Trees do not need a visited set when the structure truly has no cycles and each child is reached once.

## Why it matters

The traversal touches each node once in O(n) time. Extra space depends on maximum width for BFS or depth/pending branches for DFS. Use an explicit stack when recursion depth can exceed the runtime’s call-stack limit.

## A practical example

```js
function breadthFirst(root) {
  if (!root) return [];
  const queue = [root],
    values = [];
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    values.push(node.value);
    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }
  return values;
}
// An index avoids repeatedly shifting all queue elements.
```

## Common mistakes

Do not call every nested object a tree without checking for shared references or cycles. That changes the traversal contract.

## Complete DFS and compare traversal memory

```ts
type Tree = { value: number; left?: Tree; right?: Tree };
function preorder(root?: Tree): number[] {
  if (!root) return [];
  const stack: Tree[] = [root],
    result: number[] = [];
  while (stack.length) {
    const node = stack.pop()!;
    result.push(node.value);
    if (node.right) stack.push(node.right);
    if (node.left) stack.push(node.left);
  }
  return result;
}
```

Preorder visits root, left, right; pushing right first makes the LIFO stack visit left first. Inorder visits left/root/right and postorder left/right/root. Tree traversal is O(n) time. DFS auxiliary memory is O(h), worst O(n) for skewed trees; BFS uses O(w) for maximum width. Output storage is separate. For graphs, cycles require a visited set; a tree-only algorithm is not automatically graph-safe.
