## The idea

External API data and model output remain unknown until checked. A schema can prove a shape and local constraints, but cannot prove factual accuracy, source grounding, ownership or permission. Keep those checks explicit.

## Why it matters

Use a result union to distinguish transport failures, invalid JSON, schema failures and successful data. For streaming responses, partial chunks are not a finished valid document. Bound request and output sizes, support cancellation, and validate the completed value. If a provider accepts JSON Schema, verify its supported subset; a TypeScript type or arbitrary Zod transform cannot automatically become a provider-enforced contract.

## A practical example

```ts
import * as z from "zod";
const Suggestion = z.strictObject({
  topic: z.string().min(1).max(120),
  minutes: z.number().int().min(5).max(90),
});
type Suggestion = z.infer<typeof Suggestion>;
type DecodeResult =
  | { ok: true; data: Suggestion }
  | { ok: false; reason: "json" | "schema" };
function decode(text: string): DecodeResult {
  let raw: unknown;
  try { raw = JSON.parse(text); }
  catch { return { ok: false, reason: "json" }; }
  const parsed = Suggestion.safeParse(raw);
  return parsed.success
    ? { ok: true, data: parsed.data }
    : { ok: false, reason: "schema" };
}
```

## Common mistakes

Never execute a model-supplied command merely because it matches a schema. Authorize each tool on the server using the real session. A valid topic string can still contain invented facts or hostile instructions. Do not render generated HTML unsafely or put private API keys into client bundles.

## Try it yourself

Test malformed JSON, missing fields, negative minutes, an extra command property and a valid but factually incorrect suggestion. Explain which failures the schema catches and which need product or server policy.

## Interview checkpoint

Explain the example aloud, predict its inferred types, and describe one runtime failure that compilation cannot prevent. Then implement the exercise without using any or an unchecked assertion to bypass the problem.
