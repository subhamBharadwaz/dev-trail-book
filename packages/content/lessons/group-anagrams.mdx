## The idea

For lowercase English strings, sorting a word’s characters gives a simple canonical key. Words with the same key belong in the same group. A character-frequency signature can avoid per-word sorting when the alphabet is fixed and the key format is unambiguous.

## Why it matters

Explain the input alphabet before choosing the key. With n words of maximum length k, sorting-based grouping takes roughly O(n k log k) time plus output and key storage. The plan records Group Anagrams as pending; a correct grouping matters more than memorizing one implementation.

## A practical example

```js
function groupAnagrams(words) {
  const groups = new Map();
  for (const word of words) {
    const key = word.split("").sort().join("");
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(word);
  }
  return [...groups.values()];
}
console.log(groupAnagrams(["eat", "tea", "tan", "ate"]));
```

## Common mistakes

Do not assume every Unicode string is interchangeable with lowercase ASCII. Character representation and normalization are contract choices.
