## The idea

An Effect synchronizes a component with an external system, such as a subscription, timer, or browser API. It is not the default place to calculate data.

## Why it matters

Keep event-specific work in event handlers. Derive values during rendering. Use an Effect when an external resource needs to stay synchronized with the rendered component.

## A practical example

```tsx
import { useEffect, useState } from "react";

export function OnlineStatus() {
  const [online, setOnline] = useState(navigator.onLine);
  useEffect(() => {
    const update = () => setOnline(navigator.onLine);
    window.addEventListener("online", update);
    window.addEventListener("offline", update);
    return () => {
      window.removeEventListener("online", update);
      window.removeEventListener("offline", update);
    };
  }, []);
  return <p>{online ? "Online" : "Offline"}</p>;
}
```
