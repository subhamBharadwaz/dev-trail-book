## The idea

A Vite production build turns your application into static files. Vercel can build those files and serve them through its hosting platform.

## Why it matters

Check the production build locally before connecting the repository. Set the framework to Vite, build command to bun run build, and output directory to dist.

## A practical example

```bash
bun install
bun run build
bun run preview

# In Vercel project settings:
# Framework preset: Vite
# Build command: bun run build
# Output directory: dist
```
