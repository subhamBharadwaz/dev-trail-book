## The idea

A closure is a function together with access to its surrounding lexical environment. That access remains available even after the outer function has returned.

## Why it matters

Closures let you keep state private, create reusable handlers, and understand why a callback reads a particular value.

## A practical example

```js
function createCounter() {
  let count = 0;
  return () => ++count;
}

const next = createCounter();
console.log(next()); // 1
console.log(next()); // 2
```

## Try it yourself

Create two counters. Call one three times and the other once. Explain why their values stay independent.
