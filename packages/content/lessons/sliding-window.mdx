## The idea

A sliding window tracks a contiguous range while its endpoints move forward. For the longest substring without repeated characters, remember the most recent index of each character and move the left boundary past a repeat that lies inside the current window.

## Why it matters

The left boundary must never move backward. This is why the update uses Math.max. With the usual map-operation assumptions, each character is processed once and the scan takes expected O(n) time. This example uses JavaScript UTF-16 indexing; define a different representation if the problem requires grapheme clusters.

## A practical example

```js
function longestUnique(text) {
  const last = new Map();
  let left = 0,
    best = 0;
  for (let right = 0; right < text.length; right++) {
    const char = text[right];
    if (last.has(char)) left = Math.max(left, last.get(char) + 1);
    last.set(char, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

## Common mistakes

Do not apply sliding windows when the required property cannot be maintained by justified endpoint movements.
