## The idea

The plan uses six focused study days and a review/rest day. A normal six-hour allocation is 90 minutes technical depth, 90 implementation/debugging, 60 DSA, 60 interview practice, and 60 applications/outreach. Breaks and meals sit outside those blocks.

## Why it matters

Run the learning loop in order: recall, check gaps, build a proof, break/debug it, explain aloud. On a constrained day, use the two-hour fallback. On a very difficult day, use the twenty-minute minimum and resume normally afterward instead of doubling the next workload.

## A practical example

```js
const normalMinutes = {
  technicalDepth: 90,
```

## Common mistakes

Do not restart all previously completed topics automatically. Use a recall check to find the actual gap.
