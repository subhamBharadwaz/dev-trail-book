## The idea

Two-pointer algorithms maintain positions whose movement is justified by an invariant. In a sorted numeric array, a sum below the target lets you move the left pointer right; a sum above the target lets you move the right pointer left. Without sorting, that reasoning is invalid.

## Why it matters

The plan’s Two Pointers #1–2 are unnamed. Use Sorted Pair Sum and ASCII Palindrome as equivalent practice if the original list is unavailable. Sorting first changes time cost and may require preserving original indices, so do not conceal that preprocessing.

## A practical example

```js
function sortedPair(nums, target) {
  let left = 0,
    right = nums.length - 1;
  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) return [left, right];
    if (sum < target) left++;
    else right--;
  }
  return null;
}
// nums must already be sorted in ascending order.
```

## Complete the second Two Pointers exercise

```ts
function isAsciiPalindrome(input: string): boolean {
  const value = input.toLowerCase();
  const allowed = (c: string) => /^[a-z0-9]$/.test(c);
  let left = 0,
    right = value.length - 1;
  while (left < right) {
    if (!allowed(value[left])) {
      left++;
      continue;
    }
    if (!allowed(value[right])) {
      right--;
      continue;
    }
    if (value[left++] !== value[right--]) return false;
  }
  return true;
}
```

The contract deliberately keeps ASCII letters and digits only. Test empty input, punctuation-only input, mixed case, one character and a mismatch. Each pointer advances monotonically: O(n) time. This implementation allocates a lowercase copy, so auxiliary space is O(n); do not claim O(1) total space. This is an explicit equivalent for the second unnamed PDF exercise.
