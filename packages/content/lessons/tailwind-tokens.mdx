## The idea

Design tokens are named decisions: a surface color, text color, spacing step, or corner radius. Shared names make consistent interfaces easier to maintain.

## Why it matters

Use semantic tokens for meaning, such as background and muted text. A theme can then change the values without changing every component.

## A practical example

```css
@import "tailwindcss";

@theme {
  --color-trail-600: #267252;
  --font-sans: "Geist Variable", sans-serif;
}

:root {
  --surface: #ffffff;
  --text: #202922;
}

.card {
  background: var(--surface);
  color: var(--text);
}
```
