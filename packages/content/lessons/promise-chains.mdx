## The idea

A promise represents an eventual settlement. A then handler returns a new promise: returning a value fulfills the next step, returning a promise adopts its outcome, and throwing rejects the next step. A catch handles a rejection and can recover by returning a value or continue failure by throwing.

## Why it matters

Always return or await asynchronous work that the surrounding operation depends on. Promise.all is useful when every result is required; allSettled preserves individual outcomes when partial success is useful. Neither automatically cancels remaining operations when one rejects.

## A practical example

```js
Promise.resolve(2)
  .then((value) => value * 3)
  .then((value) => {
    throw new Error(`Unexpected ${value}`);
  })
  .catch((error) => ({ ok: false, message: error.message }))
  .then((result) => console.log(result));
// catch returns a value here, so the final step is fulfilled.
// A finally handler normally preserves the earlier outcome,
// but a thrown error or rejected return can replace it.
```

## Common mistakes

Forgetting to return a nested asynchronous operation can make the outer chain finish too early and lose its error path.

## Try it yourself

Build a three-step chain with one rejected step. Compare recovery by returning a value with propagation by throwing again.

## Combinators, ordering and failure behavior

```ts
async function loadDashboard() {
  const [profile, activity] = await Promise.all([
    fetch("/api/profile").then(check),
    fetch("/api/activity").then(check),
  ]);
  return { profile, activity };
}
function check(response: Response) {
  if (!response.ok) throw new Error(String(response.status));
  return response.json();
}
```

Promise.all preserves input ordering and rejects when a member rejects; it does not automatically cancel the other requests. allSettled waits for every result, useful for explicitly independent partial success. race settles on the first settled member. any fulfills on the first fulfillment, and rejects with AggregateError if all reject. A timeout race does not stop underlying work; pass cancellation where supported. Returning a value from catch recovers the chain; throwing keeps it rejected. finally normally preserves the outcome, but a thrown error or rejected returned promise can replace it.
