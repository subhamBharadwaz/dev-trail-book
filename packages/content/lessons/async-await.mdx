## The idea

An async function always returns a promise. Await pauses that function until a promise settles; it does not block the browser thread.

## Why it matters

Start independent work together. Await dependent work in order. Put error handling at a boundary that can explain or recover from a failure.

## A practical example

```js
async function loadDashboard() {
  const [profile, projects] = await Promise.all([
    fetch("/api/profile"),
    fetch("/api/projects"),
  ]);
  if (!profile.ok || !projects.ok) {
    throw new Error("Dashboard could not be loaded");
  }
  return { profile: await profile.json(), projects: await projects.json() };
}
```
