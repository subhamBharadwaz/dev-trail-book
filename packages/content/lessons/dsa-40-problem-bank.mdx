## How to use this bank

 This is a curated set of 40, not a claim that 40 solutions are already mastered. Use existing notes for pattern explanations and worked examples, attempt each problem independently, then use the original statement/editorial to check your reasoning. Full solutions for every listed problem are not included here.

For each attempt record: clarified contract, brute force, invariant, improved approach, time/space complexity, empty/duplicate/boundary cases, actual working code, hints used and two-day/seven-day re-solve dates. Do not count a copied answer as an independent solve.

## Interview drill

### When is a problem understood?

You can independently explain the invariant, implement a correct solution, analyze complexity and handle edge cases on a later re-solve.

### Should you finish all 40 before applying?

No. Applications start in week one; use role requirements and actual interview feedback to prioritize practice.



Contains Duplicate and Valid Anagram are explicit HashMap equivalents; sorted pair search and ASCII Valid Palindrome are explicit Two Pointers equivalents.

## Try it yourself

Pick four weak patterns, solve one from each, and schedule two spaced re-solves. Keep optional heaps out until the core is reliable.
