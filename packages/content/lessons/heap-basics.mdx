## The idea

A binary min-heap maintains a partial order: each parent is no greater than its children. The minimum is at the root, but the array is not globally sorted. Insertion appends the value and restores the invariant by moving it upward.

## Why it matters

 Use them for repeated minimum/maximum access or bounded top-k problems when the trade-off is justified. This example implements insertion only; a complete priority queue also needs removal and downward repair.

## A practical example

```js
function pushMinHeap(heap, value) {
  heap.push(value);
  let i = heap.length - 1;
  while (i > 0) {
    const parent = Math.floor((i - 1) / 2);
    if (heap[parent] <= heap[i]) break;
    [heap[parent], heap[i]] = [heap[i], heap[parent]];
    i = parent;
  }
}
// Insertion: O(log n); minimum lookup at heap[0]: O(1).
```
