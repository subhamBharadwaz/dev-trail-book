## The idea

An HTTP API contract includes method semantics, input shape, response shape, status codes, pagination, and failure behavior. Parse inputs at the boundary and return errors that help the caller recover without exposing internal details.

## Why it matters

Bound page size and use a deterministic ordering. Offset pagination is simple but may shift under concurrent writes; a cursor can describe a stable position when designed with the ordering key and a tie-breaker. Neither approach replaces authorization over the returned rows.

## A practical example

```ts
function parsePage(url: URL) {
  const raw = url.searchParams.get("limit") ?? "20";
  if (!/^\d+$/.test(raw)) throw new Error("Invalid page size");
  const limit = Number(raw);
  if (!Number.isSafeInteger(limit) || limit < 1 || limit > 100) {
    throw new Error("Page size must be 1–100");
  }
  return { limit, cursor: url.searchParams.get("cursor") };
}
```

## Common mistakes

Do not trust query strings because they came from your own UI. An external caller can supply different values.
